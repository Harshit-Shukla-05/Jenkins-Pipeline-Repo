How to create shared library :

> In Github
    >> Create a repo
    >> create folder with name "vars"
    >> Inside folder "vars" create file with name "<file_name>.groovy" 
    >> create called "call"
    >> Demo :
        Repo/vars/hello.groovy

        def call(){
            //whatever you are writing in steps write here directly
            echo "hello world"
        }

    >> save

    NOTE : "vars",".groovy" and "call" ,names are case-sensitive and should be taken care


> In Jenkins
    >> Goto Manage Jenkins --> system --> Global Trusted pipeline libraries
    >> Click Add
    >> Name (anything like shared)
    >> Default Version : (name of Github branch directly)
    >> Retrival method : (select "Modern SCM")
        >>> Source code management (select "Git")
            >>>> Project Repository (Ex-  https://<repo_name>)
            >>>> Credentials (For Public not req, for private add github id pswd)
    >> save

> In Jenkins
    >> Go to pipeline --> pipeline scripts
    >> In first line (before "pipeline" keyword)  write CMD : @Library("<library_name_like_shared") _

       NOTE : there is a space and "_" at last ,like " _"
    
    >> write as below to use

        stage("hello_stage"){
            steps{
                script{
                    <groovy_file_name_only>()      // Ex-  hello()  because file name is "hello.groovy" in git
                }
            }
        }
